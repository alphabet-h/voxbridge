## 運用ルール

1. **設計の正は 01〜03 です。** 実装と食い違ったら 01〜03 が正。実装のほうを直す
2. 新しい文書を追加するときは**連番を続け、この索引に登録**する。`04`〜`07` は空けてある
3. `08` と `09` は番号を固定する。**01〜03 とは扱いが違う** — `08` は流動（作業ログ・申し送り）、`09` は未整理の入力（受け皿）
4. 完了した項目は削除せず、**「完了」と印を付けて当時の記録として本文を残す**。なぜそう決めたかが消えると、同じ議論を半年後にやり直すことになる

## 09 の書き方

**症状 → いまどうなっているか（調べた事実）→ 直す場所の当たり**、の順で書く。

**ここで実装順を決めないこと。** 決めるのは 08。
