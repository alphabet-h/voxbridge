# 09 フィードバック

触って気づいたことの置き場。**ここで実装順を決めないこと** — 決めるのは [08](08-next-steps.md)。

## 書き方

| | |
|---|---|
| ID | `F-1` から連番。消さない |
| 種類 | 不具合 / 要望 / 質問 / 見た目 |
| 状態 | 未着手 / 調査中 / 完了（§ 参照）/ 見送り（理由） |

本文は **症状 → いまどうなっているか（調べた事実）→ 直す場所の当たり**、の順で書く。

「調べた事実」を飛ばさないこと。症状と要望だけが並ぶと、読み返したときに
**そのとき何が分かっていたのか**が消えていて、調査からやり直しになる。

完了した項目は削除せず、**「完了」と印を付けて本文を残す**。
